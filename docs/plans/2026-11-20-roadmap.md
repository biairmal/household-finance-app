# Household Finance App: Build Roadmap

**Spec:** `/mnt/project-files/design/2026-11-20-household-finance-app-design.md` (v5 mockups: https://claude.ai/artifact/KvNZnkqRkAadqbaBJBUMaQ, bottom row)

The spec covers six subsystems. Each one gets its own plan and ends in working, testable software. They run in this order, because each depends on the ones before it, and the spec requires the risky checks to come before any feature work.

| # | Plan | Delivers | Depends on | Status |
|---|------|----------|------------|--------|
| 1 | **Spikes** (`2026-11-20-plan-1-spikes.md`) | Expo app skeleton on both phones, plus a pass/fail answer on the 5 risks in spec §10 | none | Gate passed (storage, sign-in); Drive sharing still open |
| 2 | **Domain core** (`2026-11-20-plan-2-domain-core.md`) | Pure TypeScript money logic: balances, pockets, budgets, bills, goals, rules, duplicates, op log merge, export. Fully unit tested. | 1 (repo exists) | Done (branch `plan-2-domain-core`) |
| 3 | **Local store + v5 screens** (`2026-11-21-plan-3-local-store-screens.md`) | SQLite-backed store over the op log, and every v5 screen working offline on one phone with manual entry | 1, 2 | Written |
| 4 | Screenshot import | Edge service `/extract` (Gemini) and the scan → review → save flow with rules, duplicates and transfer pairing | 2, 3 | Later |
| 5 | Household + sync | Google sign-in, household create/join, Drive op-log sync between both phones, conflict notice | 2, 3 | Later |
| 6 | Reminders, export, settings | Android local notifications, Google Calendar events, CSV/JSON export, remaining Settings screens | 3, 5 | Later |

**Gate after Plan 1:** if spike 2 (iPhone storage) or spike 3 (iPhone sign-in) fails, stop and decide with Bia before Plan 3 (spec §10). Plans 3–6 are written only once Plan 1's results are in, since they decide the storage layer and the Drive layout.

**Things only Bia can do (needed during Plan 1):** create the GitHub repo, the Google Cloud project with OAuth client IDs, the Cloudflare account, the Gemini API key, collect 20 real screenshots from BCA, Jago and GoPay, and install builds on both phones.
